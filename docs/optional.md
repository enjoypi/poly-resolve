# 可选功能

已评估、暂不实现的功能；实现时移入 requirements.md 并从本文件删除。

## 免打扰时段

- 用途：夜间与周末少被打扰
- 时段：按星期与起止时刻配置，可跨午夜，按配置的固定时区偏移计算；时段重叠时拒绝启动
- 规则：时段内照常收集、分级与分析，通知暂存；时段结束后暂存的通知合并为一条，期间已结束的话题注明最终状态；与停机恢复的汇总合并，不重复发送
- 待定：优先级不低于另设穿透阈值的话题是否照常通知

## 关键词高亮

- 用途：扫读时一眼看到本人名字、项目代号、“截止”“上线”等词
- 规则：词或正则的有序列表，靠前的优先，可分别区分大小写；作用于消息表、话题时间线与分析结论；只改显示，不外发、不影响优先级；正则无效时拒绝启动
- 待定：词表放服务配置（各设备一致、进版本库）还是浏览器本地（不进版本库、各设备各配）

## 全文搜索

- 用途：找很久以前的某句话，不必先猜时间范围
- 规则：消息查看可给一个搜索词，系统在全部历史正文里查找，可与时间范围、来源叠加；纯本地，不外发
- 代价：中文按三字组建索引，搜索词至少 3 个字；索引是正文的又一份明文，保留期清除正文时一并清除

## 订阅数据源

- 用途：把网站、博客、程序更新等公开信息纳入话题
- 来源：两类，优先站点直连
  - 站点直连：指定站点按其公开接口拉取；只参考 RSSHub 所用的源站接口另行编写，不复制其代码（RSSHub 为 AGPL-3.0）；有反爬、须浏览器自动化的站点不接
  - 通用订阅源：按订阅地址拉取标准订阅格式（RSS、Atom、JSON Feed），站点原生订阅地址与本机自建 RSSHub 都可接
- 记录：条目按来源加条目标识去重，没有标识时用链接；没有时间的条目不伪造时间；内容未变时不重复处理
- 补拉：订阅通常只给最新一页，停机过久会永久缺条目，页面标“可能有缺口”
- 分级：按“消息分级与转交”的自动邮件处理：只补充已有话题、计入影响面，不另起话题、不单独触发转交
- 风险：源站改版即失效，须自行维护；订阅内容也会脱敏后外发
